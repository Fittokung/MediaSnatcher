# MediaSnatcher
Local web and desktop downloader for video and audio extraction from major social platforms using yt-dlp.


# Architecture 
- Tech Stack: Node.js (Express) + Electron + HTML5/CSS3/JS (Vanilla Modern UI)
- Progress Stream: Server-Sent Events (SSE)
- Core Engines: yt-dlp + ffmpeg
- Packaging Target: Portable .exe and NSIS Installer .exe via electron-builder
